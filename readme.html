Christocentric Rentals

WordPress + WooCommerce rental shop (local Laragon project)

Local site

  • Site: http://christocentricrentalswordpress.test/
  • Admin: wp-login.php

Quick start

  1. Start Laragon (Apache + MySQL).
  2. Ensure database christocentric_wp exists (user root, empty password).
  3. Open the site URL and complete WordPress install if needed.
  4. Activate WooCommerce, then run php scripts\setup-christocentric.php.

Full documentation

See README.md in this folder for setup, scripts, and troubleshooting. Implementation details are in IMPLEMENTATION.md; production deploy steps are in DEPLOYMENT.md.
