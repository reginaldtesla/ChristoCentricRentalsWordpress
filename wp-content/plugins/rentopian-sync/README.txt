The plugin enables the synchronization of Rentopian system data with your company's storefront (website).

== Description ==

The plugin synchronizes Rentopian's in-system data such as inventory, price multipliers, coupons, delivery fees, and damage waiver settings with your storefront (website). It also allows visitors to place quotes or direct orders which will appear in the Rentopian system immediately.

== Installation ==

**Important!** The plugin requires the latest version of [WooCommerce](https://wordpress.org/plugins/woocommerce/ "WooCommerce") to be installed and activated.

1. Install and Activate the plugin through the 'Plugins' menu in WordPress



== Frequently Asked Questions ==

= Where is my API key? =

Login to your Rentopian system, go to the Settings => Company Details section and scroll down until the API key is located. Click on the "Copy to Clipboard" button, then paste it into Rentopian Sync plugin's Api Key Field and click the "Synchronize" button.

= What will happen with my current Woocommerce products? =

The plugin will delete all of the existing products and then import the products that are present on your Rentopian system. We highly recommend backing up your data before proceeding with the synchronization.


= The synchronization process looks stalled. What can I do? =

Go to the "Logs" section of the plugin. Any issues that arise during synchronization are recorded there.
